# Лабораторная работа 1 — Статичная страница-визитка

Портфолио-визитка студентки 3 курса КемГУ, выполненная на чистом HTML и CSS
с использованием Flexbox/Grid и адаптивной вёрсткой под три брейкпоинта.

## Технологии

- HTML5 (семантические теги)
- CSS3 (Flexbox, Grid, CSS-переменные)
- Адаптивная вёрстка: Mobile (≤767px), Tablet (768–1023px), Desktop (≥1024px)
- Figma — дизайн макетов
- MongoDB — база данных для проекта чата (в портфолио)
- Git / GitVerse — контроль версий
