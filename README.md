## Лабораторная работа №2 — Введение в jQuery

Расширение проекта-визитки (ЛР1) динамическим поведением на jQuery.

### Что реализовано

- **Выпадающее меню** — клик по бургер-кнопке → `slideToggle()`
- **Модальное окно** — открытие через `fadeIn()`, закрытие по крестику, оверлею и Escape
- **Форма обратной связи** — валидация полей + симуляция отправки через `$.ajax()`
- **Динамическая галерея** — данные из `data/portfolio.json` через `$.getJSON()`, карточки рендерятся jQuery
- **Анимации** — `fadeIn` секций при скролле, плавный скролл по anchor-ссылкам
- **Карусель навыков** — кнопки «Назад/Вперёд», автопрокрутка каждые 4 сек, точки навигации
- **Подсветка активного пункта меню** при скролле
- **Кнопка «Вверх»** — плавный скролл к началу через `.animate()`
